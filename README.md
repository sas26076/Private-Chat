# چت گروهی آنلاین موقت

این پروژه یک چت گروهی Real-Time است.

## امکانات
- صفحه ورود
- 10 کاربر آماده برای ویرایش
- همه کاربران در یک اتاق مشترک
- هر پیام فوراً برای تمام کاربران متصل ارسال می‌شود
- پیام‌ها در دیتابیس یا فایل ذخیره نمی‌شوند
- بعد از قطع اتصال/ری‌استارت سرور، تاریخچه‌ای وجود ندارد
- مناسب برای شروع و توسعه بیشتر

## تغییر نام کاربری و رمز
فایل `server.js` را باز کن و قسمت `USERS` را تغییر بده:

```js
const USERS = [
  { username: "user1", password: "pass1" },
  ...
];
```

## اجرا روی کامپیوتر

Node.js نصب باشد، سپس داخل پوشه پروژه:

```bash
npm install
npm start
```

بعد مرورگر را باز کن:

`http://localhost:3000`

## نکته مهم امنیتی
این نسخه برای شروع است. رمزها داخل کد ساده هستند و ارتباط/احراز هویت پیشرفته ندارد. برای استفاده واقعی روی اینترنت بهتر است HTTPS/WSS، هش رمز عبور، نشست امن و محدودیت‌های امنیتی اضافه شود.

## نکته درباره ذخیره پیام
پیام‌ها فقط در لحظه از طریق WebSocket بین کاربران آنلاین پخش می‌شوند و سرور آنها را در فایل یا دیتابیس نگه نمی‌دارد.
